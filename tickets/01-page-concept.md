# チケット01: Concept ページ

## 概要

ブランドストーリーを伝えるテキスト主体のページ。`tickets/README.md` の共通ルール（ヘッダー/フッター流用、フォント・CSS読み込み等）に従うこと。

## 対象ファイル（新規作成のみ）

- `concept.html`
- `css/pages/concept.css`（`css/style.css` にない見せ方が必要な場合のみ）

依存ファイルなし。他チケットと完全に並行して着手できる。

## 要件定義書の該当箇所

- 要件定義.md 2章「ブランドコンセプト」（トーン・世界観・ブランドステートメント）
- 要件定義.md 5章「サイト構成」#2 Concept

## 構成案

1. フルスクリーン・イントロ（`.hero` 相当。見出し1文＋ブランドステートメント「静けさを、纏う。」）
2. ブランドストーリー本文（2〜3段落。装飾を削ぎ落とす思想、素材へのこだわり、着る人の佇まいを大切にする姿勢について）
3. こだわりのポイント3点（見出し＋短文の組み。`.offset-grid` のようなオフセットレイアウトを流用し画像プレースホルダーと組み合わせてよい）
4. Collectionページへの導線（`.concept-teaser` 相当のセクション、CTAボタンで `collection.html` へ）

## Definition of Done

- [ ] `concept.html` が作成され、`index.html` と同一のヘッダー・フッターを持つ
- [ ] 上記4セクションの構成でコンテンツが実装されている
- [ ] 375 / 768 / 1024 / 1440px で崩れないことを確認済み
- [ ] 画像は全てプレースホルダー（`.ph` 系クラス）
