# チケット05: Checkout ページ（モック）

## 概要

購入手続きのモック。決済処理は行わず、注文確認画面までを実装する。`tickets/README.md` の共通ルールに従うこと。

## 対象ファイル（新規作成のみ）

- `checkout.html`
- `css/pages/checkout.css`（必要な場合のみ）
- `js/pages/checkout.js`

## 依存するAPI（チケット00）

```html
<script src="js/cart.js"></script>
```

```js
TacetCart.getCart()
TacetCart.getSubtotal()
TacetCart.clearCart()
```

チケット00未完成でも、このシグネチャ前提でコードを書いて進めてよい。

- 要件定義.md 5章「サイト構成」#6 Checkout
- 要件定義.md 8章「技術要件」（決済処理は対象外）

## 構成案

1. 配送先情報の入力フォーム（氏名・住所・電話番号等。入力値の送信先は無いため、送信してもページ内遷移のみでよい。実際に外部送信やバリデーションAPI連携は行わない）
2. 注文内容の確認（`TacetCart.getCart()` の内容と `getSubtotal()` を表示）
3. 「注文を確定する」ボタン → クリックで注文確認完了画面（同一ページ内で表示切り替え、または別セクション表示）に遷移し、`TacetCart.clearCart()` を呼んでカートを空にする
4. 完了画面には「ご注文ありがとうございます」的なメッセージと、Homeへ戻る導線を表示

## Definition of Done

- [ ] `checkout.html` にカート内容・小計が表示される
- [ ] フォーム入力→「注文を確定する」で完了画面に切り替わる
- [ ] 完了後、`localStorage` のカートが空になり、ヘッダーのカート件数も0になる
- [ ] 実際の決済APIやサーバー通信を一切行っていない
- [ ] 375 / 768 / 1024 / 1440px で崩れないことを確認済み
