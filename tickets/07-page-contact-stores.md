# チケット07: Stores / Contact ページ

## 概要

店舗情報とお問い合わせを掲載するページ。`tickets/README.md` の共通ルールに従うこと。

## 対象ファイル（新規作成のみ）

- `contact.html`
- `css/pages/contact.css`（必要な場合のみ）

依存ファイルなし。他チケットと完全に並行して着手できる。

## 要件定義書の該当箇所

- 要件定義.md 5章「サイト構成」#8 Stores / Contact

## 構成案

1. ページ見出し（「Stores」または「Stores / Contact」）
2. 店舗一覧（架空の店舗2〜3件。店舗名・住所・営業時間・電話番号を記載。地図の埋め込みは行わず、テキストのみで良い）
3. お問い合わせフォーム（お名前・メールアドレス・お問い合わせ内容の入力欄＋送信ボタン。送信先は無いため、実際の送信処理は行わずページ内メッセージ表示のみで良い）

## Definition of Done

- [ ] `contact.html` が作成され、`index.html` と同一のヘッダー・フッターを持つ
- [ ] 店舗一覧とお問い合わせフォームが実装されている
- [ ] フォーム送信時に外部通信を行わず、送信完了メッセージ等の表示のみで完結している
- [ ] 375 / 768 / 1024 / 1440px で崩れないことを確認済み
