# チケット06: Lookbook ページ

## 概要

着用イメージを見せるビジュアルギャラリーページ。`tickets/README.md` の共通ルールに従うこと。

## 対象ファイル（新規作成のみ）

- `lookbook.html`
- `css/pages/lookbook.css`（必要な場合のみ）

依存ファイルなし。他チケットと完全に並行して着手できる。

## 要件定義書の該当箇所

- 要件定義.md 5章「サイト構成」#7 Lookbook
- 要件定義.md 6章「画像・映像素材」（プレースホルダーで仮組み）
- 要件定義.md 7章「デザイン要件」（重なり・ずらしのレイアウトアクセント）

## 構成案

1. ページ見出し（「Lookbook」＋シーズン表記など短い導入）
2. ビジュアルグリッド（10〜16枚程度の `.ph` プレースホルダーを、大小・縦横比を変えながら重なり・ずらしを効かせて配置。`index.html` の `.offset-grid` を発展させ、3〜4種類のサイズパターンをランダムに組み合わせるイメージ）
3. Collectionページへの導線（「このスタイルを見る」的なCTA）

## Definition of Done

- [ ] `lookbook.html` が作成され、`index.html` と同一のヘッダー・フッターを持つ
- [ ] 大小・ずらしを伴うビジュアルグリッドが実装されている
- [ ] 375 / 768 / 1024 / 1440px で崩れないことを確認済み（モバイルでは縦積みで可）
